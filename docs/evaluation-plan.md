# Протокол до измерения ответов

Набор: 60 вопросов по GeoNames City Facts RU v2 из отложенного test ДЗ3.
Выбор кандидата использует только 8 val-примеров и не использует этот test.
Полный индекс train — 1536 исходных вопросов. Группы стран разделены заранее.

Три критических среза (по 20 вопросов) зафиксированы до генерации:

- `country`: основной факт задачи; неверная страна меняет смысл ответа.
- `population`: точное следование снимку, а не приблизительное число из памяти.
- `timezone`: точная строка зоны IANA; не эквивалентна произвольному UTC-смещению.

`geography` пересекается с этими срезами и содержит те же 60 строк.
Размеры пересекающихся срезов не суммируются для общего n.

У обеих моделей одинаковые system, greedy decoding, seed=42, лимит 32 новых
токена, disabled thinking и строгий JSON scorer. `expected` не передаётся
модели. Метки A/B/C распределены поровну, порядок вариантов перемешан
детерминированно до измерения. Baseline — точная HF-ревизия исходной Qwen,
а не адаптер ДЗ5: по условию первоначальная точка отсчёта — база.

Gate: нулевой допуск регрессии overall accuracy/format_rate и accuracy
каждого из трёх критических срезов; все три behavioral проходят. Ошибки,
NaN, missing или несовместимость означают отказ. Отказ допустим и не требует
дополнительного обучения; champion не меняется. После просмотра результатов
этот протокол и пороги не подстраиваются. Синтетические тесты и испорченная
копия ответов не выдаются за измерение реальной модели.
